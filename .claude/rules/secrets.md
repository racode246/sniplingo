# Rule: シークレット / 個人設定の扱い

このアプリは既定で**完全無料・キー不要**（Google 無料エンドポイント + オフライン Argos）。DeepL は任意機能で、有効化したユーザーだけが API キーを設定する。

- **API キーをリポジトリに置かない**。コード・テスト・サンプル・コミットに**ハードコード禁止**。
- DeepL キー等のユーザー設定は **`%APPDATA%\SnipLingo\config.json`**（ユーザー領域）にのみ保存する。リポジトリ内には置かない。
- キーやトークンを**ログ・例外メッセージ・診断出力に出さない**。表示が必要な場合は `****` でマスク。
- `config` はロード時に**信頼しない**: 型を検証し、未知キーは無視し、欠損は既定値で補う。壊れた JSON でクラッシュさせない。
- `.gitignore` は `config.json` と `*.argosmodel` を含む（万一プロジェクト内に生成されても追跡しないための保険）。
- ネットワーク先は翻訳エンドポイントのみ。テレメトリ・外部送信を勝手に追加しない。
