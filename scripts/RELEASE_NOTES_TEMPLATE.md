Windows 11 向けゲーム翻訳オーバーレイ。範囲選択 → Windows OCR(英語) → 日本語翻訳 → 透過オーバーレイ表示。

## 使い方
1. zip を展開して `SnipLingo.exe` を実行（インストール不要・トレイ常駐）
2. `Ctrl+Alt+R` か トレイ「範囲を選択して翻訳」で範囲をドラッグ → 自動翻訳
3. オーバーレイはドラッグで移動（位置記憶）、× / 右クリック / `Esc` で閉じる
